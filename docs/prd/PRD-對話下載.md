# PRD:對話下載

> 狀態:已確認
> 日期:2026-10-05

## 背景(為什麼要做)

系統目前沒有保存對話紀錄(#4 尚未實作),使用者關掉分頁對話就消失。
實際使用情境是把問答內容整理成研究筆記、貼進報告,因此需要一個把當前對話帶走的方式。

## 目標

1. 使用者可在網頁右上角點一個按鈕,下載當前對話
2. 下載的是 Markdown 檔,可直接貼進筆記軟體或報告
3. 檔頭含日期與網址,貼進報告時有出處可標

## 不做什麼(Non-goals)

- 不做對話紀錄的伺服器端保存(屬 #4 的範圍)
- 不下載「你可以接著問」的延伸問題建議
- 不做 PDF、Word 等其他格式
- 不做跨裝置同步或歷史對話列表

## 方案概述

**純前端 JavaScript**,不動 Python、不碰回答流程。按鈕與匯出都在瀏覽器端完成:
掃描畫面上的對話節點、組成 Markdown、以 Blob 觸發下載。

比較過的替代方案:

| 方案 | 否決原因 |
|---|---|
| 後端產檔 + 前端按鈕 | 需加 HTTP endpoint,Chainlit 支援有限,且會動到回答流程 |
| 訊息內的 `cl.Action` 按鈕 | 做不到固定於右上角,且每則回答都多一顆按鈕 |

純前端最大的好處是**失效時只是按鈕沒作用,聊天功能完全不受影響**。

### 檔案異動

| 檔案 | 動作 |
|---|---|
| `public/download-conversation.js` | 新增:按鈕與匯出邏輯 |
| `public/custom.js` | 新增:載入器。Chainlit 的 `custom_js` 只接受單一檔案,而既有的去浮水印功能要保留 |
| `public/remove-watermark.js` | 加上 `readyState` 防護(見下) |
| `.chainlit/config.toml` | `custom_js` 改指向 `custom.js`,帶版本號避免瀏覽器快取 |

### 匯出格式

```markdown
# 夷問對話紀錄

- 日期:2026-10-05 22:14
- 網址:https://yijianzhi.org

---

## 問
王三一的父親為什麼也要死?

## 答
〈不孝震死〉原文沒有記載⋯⋯
```

檔名:`夷問對話_2026-10-05_2214.md`

延伸問題按鈕在 DOM 中是獨立元素,不在回答本文的區塊內,掃描時天然排除;
僅需再移除本文結尾的「你可以接著問:」標題。

## 驗收情境

| # | 操作 | 預期結果 |
|---|------|----------|
| 1 | 進入網頁,尚未提問 | 右上角出現下載按鈕,呈停用狀態 |
| 2 | 問答數輪後點下載 | 取得 Markdown 檔,內容與畫面一致,中文正常 |
| 3 | 檢視檔案 | 檔頭有日期與網址;**不含**延伸問題建議 |
| 4 | 下載後繼續聊天 | 問答、追問、離題婉拒皆不受影響 |

## 風險與備註

- **依賴 Chainlit 的 DOM 結構**(`div[id^="step-"]`、`.ai-message`、`.message-content`)。
  Chainlit 改版可能使其失效,症狀為按鈕沒作用,不影響聊天。程式內已加註記提醒
- `remove-watermark.js` 原本只在 `DOMContentLoaded` 時初始化。改由載入器動態插入後,
  該事件可能已經觸發完畢,故補上 `readyState` 判斷。此為必要的正確性修正,
  行為與原本一致
