# 迴歸測試清單

凡動到 **prompt、模型、檢索邏輯、語料切分**,部署前必須整輪跑完。
測試環境:本機 `docker compose up` 或直接對 https://yijianzhi.org。

> 案例來源:1150903 老師回饋意見。測完在表格記錄日期與結果(✅/❌ + 備註)。

## A. 基本功能(冒煙測試)

| # | 操作 | 預期結果 |
|---|------|----------|
| A1 | 開啟首頁 | 顯示「夷問」介面,輸入框文字為「夷**堅**志」(不是夷間志) |
| A2 | 問「夷堅志裡有哪些關於鬼的故事?請舉一兩個例子」 | 串流回答,引用具體條目(如金釵辟鬼) |
| A3 | 檢視整段回答 | 全部為繁體中文,無簡體字、無不必要英文 |

## B. 多輪對話(對應 issue:接續追問)

| # | 操作 | 預期結果 |
|---|------|----------|
| B1 | 先問「冥府審判相關故事有哪些?」→ 系統條列 1、2 | — |
| B2 | 接著問「第 2 個故事的詳細內容?」 | 能正確接續前文,講對應條目,不可答非所問或當成新問題 |
| B3 | 問女性相關故事 → 縮小到某條目 → 追問該條目內特定詞的意思 | 回答該條目語境下的意義,而非通用釋義 |

## C. 回答品質(拼接與深度)

| # | 操作 | 預期結果 |
|---|------|----------|
| C1 | 問「陸氏負約」故事中,信是誰交給陸氏的? | 依原文:急足(送信差使)送達;**不得**說成鄭某弟弟轉交(鄭從弟甸僅為文末資料來源) |
| C2 | 問「紙交子」條目講了哪些事? | 分開講:(1) 祝版誤書年號靖康 (2) 發行紙交子八年即廢;**不得**融合成「紙交子上寫錯靖康」 |
| C3 | 問「王父的死因背後有什麼理由或意涵?」 | 有詮釋分析(因果、時代背景),不只是複述死因情節;詮釋處應標明為詮釋 |
| C4 | 問一個與夷堅志無關的問題(如「今天天氣如何」) | 禮貌說明僅回答《夷堅志》相關問題 |

## D. 部署健康檢查(每次上線後)

| # | 操作 | 預期結果 |
|---|------|----------|
| D1 | `curl -s -o /dev/null -w "%{http_code}" https://yijianzhi.org/` | 200 |
| D2 | 伺服器 `sudo docker compose ps` | STATUS 為 Up |
| D3 | 實際問 A2 的問題 | 正常串流回答(確認 OpenAI key 有效) |
